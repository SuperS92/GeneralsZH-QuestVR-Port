# Quest controls

The interaction follows [Gonzorro's GeneralsVR](https://github.com/Gonzorro/GeneralsVR). This guide describes the bindings in this standalone port.

| Action | Control |
| --- | --- |
| Point at units, terrain or the HUD | Right controller laser |
| Select or give a context order | Press and release the right trigger |
| Select several units | Hold the right trigger, sweep a box over the ground, then release |
| Add units to the current selection | Hold the left grip while clicking units or starting a selection box with the right trigger |
| Give a context order directly | Right A |
| Cancel a command or clear selection | Left trigger |
| Force attack | Hold left Y while giving the order |
| Move around the map | Left stick; movement follows your view direction |
| Turn | Right stick left/right |
| Move closer to / farther from the map | Right stick forward/back |
| Resize the world | Hold both grips and change the distance between your hands |
| Tilt the battlefield (Tabletop) | Hold both grips and flick the right stick up/down for 15° steps; return to centre between steps |
| Reset battlefield tilt | Hold both grips and flick the right stick left |
| Rotate a building before placement | Hold right grip and move the right stick left/right |
| Place the building | Point at valid ground and release the right trigger |
| Show or hide the wrist HUD | Tap right B |
| Command wheel | Click the left stick |
| Pause / options | Choose **Menu** in the command wheel |
| Control groups | Hold right B to open the group wheel |
| Recall a group | Choose a slot with the right stick, then return it to the centre |
| Assign the selection to a group | Hold the right trigger while choosing its slot with the right stick |
| Focus a group | Recall the same group twice |
| Jump to selected units | Click the right stick |
| Jump to the latest radar event | Double-click the right stick |
| Recenter | Briefly press the left Menu button |
| Follow the selection / stop following | Hold the left Menu button |
| Switch tabletop / battlefield view | Hold both grips and click the right stick |

You can also choose wheel entries with the laser and trigger. The left trigger cancels an open wheel. Building placement keeps camera turning separate while the right grip is held.

Additive selection keeps the units already selected, including when you move to
another part of the map. It adds your units once, respects the selection limit,
and ignores empty ground and enemy units. An existing building or enemy selection
must first be replaced with a normal unit selection. Release the left grip for normal context
orders and replacement selection. Active placement, targeted abilities and menus
keep their usual controls. Holding both grips reserves input for world gestures.

Point at text fields and use the floating keyboard for match names and chat. In flat campaign scenes, the pointer operates the original menu. Story videos can be skipped with right B or the trigger; scripted 3D sequences follow the original game's skip restrictions.
